# Niaga Payment

**Niaga Payment** is a **Progressive Web Application (PWA)** built to empower **micro and small enterprises (UMKM)** — especially those with limited access to technology and who primarily rely on smartphones.  
This project simplifies digital payments and business operations through a lightweight, installable web application that works seamlessly on any device.


## 🌐 Overview

Niaga Payment can be **installed directly on smartphones** using PWA technology, allowing users to manage their business transactions anytime and anywhere — without requiring a native app installation.  
The interface is designed to be mobile-first, intuitive, and efficient for everyday business use.

---

## ⚙️ Key Features

- 📱 **PWA Installation** — Fully installable on mobile and desktop browsers.  
- 🔐 **Secure Authentication** — Integrated with **Google OAuth2** for reliable and safe login.  
- 🧾 **PDF & Excel Report Generation** — Generate and download financial reports with a single click.  
- 💳 **QRIS Payment Support** — Supports both **dynamic QRIS generation** and **manual QRIS input** for flexible payment handling.  
- 🌗 **Light/Dark Mode** — Seamlessly switch between light and dark themes for better user experience.  
- 🖥️ **Server-Side Processing** — All payment, authentication, and export processes are handled securely on the server.

---

## 💡 Purpose

Niaga Payment was developed to support **lower-income micro and small business owners** in digitizing their payment systems and financial records — even with minimal technical resources.  
By leveraging **modern web technologies**, this platform offers an accessible, low-cost solution for digital business management without requiring specialized devices or software.

---

## 🛠️ Tech Stack

- **Next.js 15 (App Router)** — Full-stack React framework for scalable web applications.  
- **TypeScript** — Ensures maintainability and type safety across the project.  
- **Prisma ORM + PostgreSQL** — Efficient, reliable database management.  
- **NextAuth (OAuth2 - Google)** — Secure authentication system.  
- **Redis** — Used for caching and visitor analytics.  
- **Report Generation (Server-Side)** — Exports data as PDF or Excel via backend processing.  
- **Tailwind CSS + Shadcn/UI** — Responsive UI components with built-in light/dark mode support.

---

## 🚀 Deployment

Niaga Payment is fully optimized for **production environments**, featuring server-side rendering, caching strategies, and scalable API routing.  
It’s lightweight, secure, and designed to perform smoothly even on entry-level mobile devices.

---

## 🧭 Vision

> Niaga Payment is more than just a digital payment tool — it’s a bridge helping small businesses embrace the digital economy with simplicity, security, and confidence.
